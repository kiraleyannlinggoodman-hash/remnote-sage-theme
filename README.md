# 🌿 Sage Valley

A soft sage green theme for [RemNote](https://www.remnote.com), designed to create a calm, gentle and comfortable study environment.

## 🎨 Colour Palette

Sage Valley uses a collection of muted green tones inspired by nature.

| Colour | Hex Code | Purpose |
|---|---|---|
| Sage Green | #CDE6CA | Main theme colour |
| Light Sage | #EAF3E7 | Secondary backgrounds |
| Soft Paper | #F5FAF3 | Main reading background |
| Muted Sage | #A8C9A2 | Accent colour |
| Deep Sage | #405B43 | Secondary text |

## ✨ Features

- Soft sage green colour scheme
- Light, gentle backgrounds
- Muted green accents
- Dark green text for readability
- Minimal and distraction-free appearance
- Designed with comfortable studying in mind

## 📥 Installation

1. Open RemNote.
2. Navigate to the Custom CSS Power-up.
3. Create a new CSS snippet.
4. Paste the Sage Valley CSS.
5. Save and enable the snippet.

## 🌱 Design Philosophy

Sage Valley is inspired by the peaceful colours of nature.

Its goal is to make studying feel a little calmer through soft greens, subtle contrasts and a clean visual environment.

**Less distraction. More focus. A little more green.**
